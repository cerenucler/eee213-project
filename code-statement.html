How to Run the Code

Download or clone the repository. Open a terminal in the repository root directory, where ccpp.csv is located, and install the required libraries:

python -m pip install numpy scikit-learn

Run the scripts from the repository root directory:

python lab/w09.py
python lab/random_forest.py
python lab/rc_charging.py

The data-analysis and Random Forest scripts read ccpp.csv from the repository root. Keep the dataset file in that location when running them.

Software Versions

  • NumPy 2.5.5
