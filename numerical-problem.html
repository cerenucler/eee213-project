Numerical Problem: RC Charging Circuit

1. Problem Description and Assumptions

This problem examines the charging behavior of a capacitor in a series RC circuit connected to a DC voltage source. The capacitor voltage is calculated using Euler's method, fourth-order Runge-Kutta (RK4), and the exact analytical solution.

Circuit Parameters

Parameter Value
Source voltage (Vs)10 V
Resistance (R)1000 Ω (1 kΩ)
Capacitance (C)0.001 F (1000 µF)
Initial capacitor voltage0 V
Time step (h)0.2 s
Simulation duration5 s

Model Assumptions

  • The voltage source is an ideal constant DC source.
  • The resistor and capacitor are ideal components.
  • Resistance and capacitance remain constant.
  • The capacitor is initially uncharged.
  • Leakage current and parasitic effects are neglected.
  • The switch closes at t = 0.

Note: The circuit parameters are selected for this worked example because the assignment does not specify numerical component values.

2. Mathematical Model and Equations

Kirchhoff's Voltage Law (KVL)

Vs = VR + VC

Ohm's law:

VR = R × i

Capacitor current-voltage relationship:

i = C × dVC/dt

Differential Equation Derivation

Substituting the capacitor current equation into Ohm's law:

VR = RC × dVC/dt

Substituting into Kirchhoff's voltage law:

Vs = RC × dVC/dt + VC

Rearranging:

dVC/dt = (Vs - VC) / (RC)

The time constant is: τ = RC = 1000 × 0.001 = 1 s.

Therefore, the differential equation becomes:

dVC/dt = (10 - VC) / 1

Initial condition:

VC(0) = 0 V

3. Exact Analytical Solution

The exact solution of the RC charging differential equation is:

VC(t) = Vs × (1 - e^(-t/RC))

Using the selected circuit parameters:

VC(t) = 10 × (1 - e^(-t/1))

This analytical solution is used as an independent reference to evaluate the numerical methods.

4. Euler's Numerical Method

The general Euler update equation is:

VC(n+1) = VC(n) + h × f(tn, VC(n))

For this circuit:

VC(n+1) = VC(n) + 0.2 × (10 - VC(n))
VC(n+1) = 0.8 × VC(n) + 2

First Iteration

Initial voltage: VC(0) = 0 V.

VC(1) = 0 + 0.2 × (10 - 0)

VC(1) = 2.000000 V at t = 0.2 s.

5. Fourth-Order Runge-Kutta (RK4)

The RK4 update equation is:

VC(n+1) = VC(n) + h/6 × (k1 + 2k2 + 2k3 + k4)

Where:

k1 = f(tn, VC(n))
k2 = f(tn + h/2, VC(n) + hk1/2)
k3 = f(tn + h/2, VC(n) + hk2/2)
k4 = f(tn + h, VC(n) + hk3)

First Iteration

  • k1 = 10 V/s
  • k2 = 9 V/s
  • k3 = 9.1 V/s
  • k4 = 8.18 V/s
VC(1) = (0.2/6) × (10 + 2(9) + 2(9.1) + 8.18)

VC(1) = 1.812667 V at t = 0.2 s.
