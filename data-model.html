Data and Model

1. Dataset Description

The Combined Cycle Power Plant (CCPP) dataset contains 9,568 observations and four input features.

Dataset Source and License

Tüfekci, P. and Kaya, H. (2014). Combined Cycle Power Plant. UCI Machine Learning Repository.

DOI: 10.24432/C5002N

License: CC BY 4.0.

Features and Target

  • AT: Ambient Temperature (°C)
  • V: Exhaust Vacuum (cm Hg)
  • AP: Ambient Pressure (mbar)
  • RH: Relative Humidity (%)

Target: PE - Net Electrical Output (MW).

2. Data Quality Checks

  • Number of observations: 9,568
  • Number of columns: 5
  • Missing values: 0
  • Duplicate groups: 41
  • Extra duplicate rows: 41 (retained)
  • Unique rows: 9,527

All 41 extra duplicate rows were retained to preserve the original dataset.

Observed Value Ranges

  • AT: 1.81 - 37.11 °C
  • V: 25.36 - 81.56 cm Hg
  • AP: 992.89 - 1033.30 mbar
  • RH: 25.56 - 100.16 %
  • PE: 420.26 - 495.76 MW

3. Training and Test Split

The dataset was divided using the first 7,654 rows for training and the last 1,914 rows for testing.

  • Total observations: 9,568
  • Training set: 7,654 rows (80%)
  • Test set: 1,914 rows (20%)

The test set was kept separate during model training and used for final evaluation.

4. Week 09: Baseline and Linear Regression

Baseline Model

The baseline predicts the training mean of PE for every test observation.

Training mean of PE: 454.44 MW

Baseline test MAE: 14.72 MW

Linear Regression Results

  • Linear Regression using AT: 4.33 MW MAE
  • Linear Regression using V: 6.49 MW MAE

5. Week 10: Random Forest Regression

Random Forest Regression was applied to predict net electrical output (PE).

Model Configuration

  • Model: RandomForestRegressor
  • Number of trees (n_estimators): 100
  • Maximum features (max_features): 2
  • Random state: 42

Model Performance

  • Baseline test MAE: 14.72 MW
  • Random Forest test MAE: 2.28 MW

The Random Forest model achieved a lower test MAE than the baseline model on the specified training and test split.
